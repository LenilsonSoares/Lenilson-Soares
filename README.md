## Workflow Sênior

Este repositório usa um arquivo de regras para orientar a criação de projetos com mais qualidade, segurança e clareza.

O workflow está documentado em [`.ai-rules.md`](.ai-rules.md) e combina:

Foco principal: criar bots e aplicações organizadas, seguras e econômicas em tokens.
